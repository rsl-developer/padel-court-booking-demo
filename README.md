# Padel Court Booking Demo

Interactive single-file demo of a school padel court booking system.

## Live Demo

Once GitHub Pages is enabled, visit:

**https://rsl-developer.github.io/padel-court-booking-demo/**

## How to enable GitHub Pages

1. Go to the repository **Settings** → **Pages**
2. Under "Build and deployment", set Source to **Deploy from a branch**
3. Select branch `main` and folder `/ (root)`
4. Click Save

The site will be live in about a minute.

## Features

- Day picker for the next 14 days
- Click available slots to book
- Upload a payment receipt (client-side)
- Admin panel to confirm / reject / block slots
- Editable settings (prices, FPS, PayMe, school name)
- All data is in-memory demo mode (nothing is saved)

## Notes

This is a pure client-side demo. Refresh the page to reset all bookings.
